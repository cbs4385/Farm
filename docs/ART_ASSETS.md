# Visual asset requirements

Generated from the project (placeholder art in `Assets/_Project/Art/Placeholders`, the `*Defaults` content tables, the map builder and the code that draws things at runtime). **Everything the player sees is currently a placeholder**: flat-coloured, speckled rectangles generated by `PlaceholderArtGenerator`, plus a few solid squares drawn at runtime. This document lists every visual asset that must be created before release (task T-060), and what is missing entirely.

Rule: **replace by name.** Final art keeps the file names below so the generators, atlases and scenes pick it up unchanged. Keep original art only (CLAUDE.md non-negotiable) and record every source in `docs/ASSET_LICENSES.md`.

## 1. Technical baseline

| Item | Spec (as the placeholders are built) |
|---|---|
| Pixels per unit | 16 (one tile = 16 px = 1 world unit); point filtering, pixel-perfect camera, reference height set in `SceneSetup.RefHeight` |
| Tiles | 16x16 |
| Items / icons / crops / objects | 16x16 (objects may be taller if the collider is adjusted) |
| Characters (player, NPCs) | 16x32, four facings (`down`, `up`, `left`, `right`) |
| Portraits | 32x32 |
| UI frames | 9-slice friendly: panel 24x24, slot 18x18 |
| Format | PNG, transparent background, imported by `TextureImportPostprocessor` |
| Naming | `<category>_<name>[_<facing or frame>]` |

## 10. Maps and lighting

Each scene is generated from tiles and objects by `MapBuilder`; there are no hand-painted backgrounds. Final art should add: **Farm** (clear/overgrown stages, house, greenhouse, coop, barn), **Village** (buildings, lane, signs, lamps, fences), **Forest** (path, pond, cave mouth, brambles), **Beach** (shore, fish stall), **six interiors** plus the Community Hall (restored vs derelict states per room), **Mine** (floor sets by depth band, with the boss arena), **Harrow Wood** (dense trees, clearing, altar). Also: window light and lamp glow sprites for the night lighting (`DayNightLighting` uses a global tint only).

## 11. Horror-layer art summary

The layer ships with 1.0 and needs: Harrow Wood tiles and trees; the altar (idle and ritual states); three lore-stone sprites; three relic pickups plus inventory icons; six horror/mutant crops with growth stages; Keeper ritual robes and hooded silhouettes; fog and blood-moon weather and sky overlay; the 20 wakefulness-step tints can be shader/colour only but a few steps benefit from overlays (cracks in the ground, creeping vines, a red sky); four ending illustrations; dream/dread vignette overlay. **A 'mild' variant** is needed only for the ritual imagery (plain lights instead of offerings).

## 12. Not in the project at all (create from scratch)

- Animation clips for every character, animal, monster and tool action (the game has none)
- Title screen background and **game logo** (the main menu is text on a flat colour)
- **Application icon** and Steam library assets
- **Store page art**: capsule images (header, small, main, vertical), screenshots, trailer frames, background
- Credits screen layout
- Four ending illustrations and a festival backdrop/decor set (spring 13, summer 11, fall 16, winter 25)
- Seasonal decor for the village (snow, falling leaves, blossoms)
- Day-summary and level-up banners
- Loading / transition art (currently a black fade)

## 13. Suggested production order

1. Tiles with autotile edges, the player and villagers with walk cycles, crops and core item icons: this makes the farming loop look like a game.
2. UI frames, HUD and menu icons, portraits.
3. Buildings and map dressing for Farm and Village; animals; mine monsters and the boss.
4. Harrow Wood and the horror layer set.
5. Effects and weather, title screen, logo, ending art.
6. Store page art, capsule and screenshots (after the above exist).
