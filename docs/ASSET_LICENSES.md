# Asset and third-party licenses

Every non-code asset and every third-party component must be listed here with source and license. Only CC0, properly licensed, or self-owned assets are allowed. This file feeds the credits screen and the release checklist.

## Art, audio, fonts
| Path | Source | License | Notes |
|---|---|---|---|

## Rules
- Record the source URL, author, and license for every imported asset, and keep a copy of any license that requires attribution.
- No assets from Stardew Valley or other commercial games, and no text or characters from existing Lovecraft-inspired works that are not in the public domain.
- AI-generated assets (if used) must follow the project policy in the design docs and be listed here with the tool and date.
